# 15 天计划

本仓库是《企业级 CMS》课程项目的 **M2 内容模块**（`com.ylf.cms.content`，10 个文件 / 810 行）及按《分工说明》配套的依赖工程。由于小组 M1/M3 尚未交付，为保证 M2 可独立启动、联调、演示验收，仓库内置了**可连真实 MySQL 的伪 M1（账号权限）与伪 M3（分类）契约实现**——不造假数据，登录、权限、分类全部真实查库；正式模块到位后按契约替换即可。

每天推一块，当天结束时 `mvn -B -pl startup -am package` 必须是绿的。**判据写的是"能失败的东西"**：每条都给出一个跑下去会红的动作，否则绿了也证明不了什么。

|---|---|---|---|---|

## 规则

1. 每天一次提交，message 写"为什么"，不写"改了什么"。
2. AI 给的代码逐行看过再提交，改动处留 `// 人工调整：原因`。
3. 当天卡在哪、怎么解决的，追加到 `docs/ai-log.md`。
4. 某天做不完就往后退一天，不压缩后续内容去追日期——日期不重要，判据绿了才算完。
