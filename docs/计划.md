# 15 天计划

本仓库从《企业级 CMS》课程项目里把 **M4 智能体与运维**（`com.ylf.cms.ops`，28 个文件 / 1721 行）单独抽出来发布。智能体要"知道全站"，靠的是读 `@GuideCard` 注解和各模块的 Service，所以它编译不了"只有自己一个包"的形态——`ops` 对 `common` 有 27 处 import、对 `security` 7 处，另有 `catalog`、`content` 各 1 处。这就是把公共层一起带进来的原因。

每天推一块，当天结束时 `mvn -q package` 必须是绿的。**判据写的是"能失败的东西"**：每条都给出一个跑下去会红的动作，否则绿了也证明不了什么。

| 天 | 日期 | 块 | 产出 | 当天结束时能验证 |
|---|---|---|---|---|
| D1 | 11-01 | 骨架 | `pom.xml`、`CmsApplication`、`application.yml`、README、本计划 | `mvn -q package` 通过；配置里没有任何明文口令 |
| D2 | 11-02 | 公共层·结果与异常 | `Result` / `ErrorCode` / `BusinessException` / `GlobalExceptionHandler` | 造一个未捕获异常，响应体里搜不到堆栈和 SQL |
| D3 | 11-03 | 公共层·校验与工具 | 参数校验、`TraceIdFilter`、`@GuideCard` 注解、工具类 | 传 `pageSize=99999` 返回 400 |
| D4 | 11-04 | 数据层 | `schema.sql`（六表 + `sys_log`）、`data.sql`、MyBatis-Plus 配置、审计填充 | 在空库里跑 `schema.sql` 能建全表；`create_time` 由框架填而非手写 |
| D5 | 11-05 | 安全层·身份 | `LoginUser` / `UserContext` / 登录注册退出 / 拦截器 | 未登录访问 `/api/**` 返回 401 |
| D6 | 11-06 | 安全层·权限 | `RoleService` 权限码、`@RequirePermission`、AOP | 作者调审核接口返回 403，且 `sys_log` 有一条 `DENIED` |
| D7 | 11-07 | 业务层·智能体要读的那两块 | `CategoryService`、`ArticleService`（列表与计数） | 智能体的建议数字与库里的 `COUNT` 对得上 |
| D8 | 11-08 | 日志·落库 | `SysLog`、`SysLogMapper`、`@Log` 切面 | 调一次写接口，`sys_log` 多一行；密码字段是 `***` |
| D9 | 11-09 | 日志·查询 | `LogController` / `LogQuery` / 排序白名单 | `sort=; DROP TABLE` 返回 400 |
| D10 | 11-10 | 智能体·站点地图 | `SiteMapCollector` / `SiteMapHolder` / `SiteMapSnapshot` | `/api/guide/pages` 出卡片，且卡片上的权限码真实存在 |
| D11 | 11-11 | 智能体·启动校验 | `site-map.yaml`、`SiteMapValidator`（C1–C5） | 故意写错一张卡片的路径，启动失败并指出是哪张 |
| D12 | 11-12 | 智能体·规则路由 | `TextNormalizer` / `IntentRouter` / `GuideCopy` | 断网、无密钥时提问仍能得到页面导航答案 |
| D13 | 11-13 | 智能体·模型通道 | `GuideLlmService` / `LlmIntentRouter` / `LlmKeyStore` / 设置接口 | 密钥填错的请求不阻塞问答，只在设置区报错 |
| D14 | 11-14 | 智能体·建议与前端 | `SuggestionService`、`GuideController`、悬浮球/卡片/高亮 | 九个引导场景（G1–G9）逐条走通 |
| D15 | 11-15 | 收尾 | 测试、ApiFox 集合、`docs/api.md`、演示脚本 | 全量测试绿；九个场景在演示脚本里各有一条命令 |

## 规则

1. 每天一次提交，message 写"为什么"，不写"改了什么"。
2. AI 给的代码逐行看过再提交，改动处留 `// 人工调整：原因`。
3. 当天卡在哪、怎么解决的，追加到 `docs/ai-log.md`。
4. 某天做不完就往后退一天，不压缩后续内容去追日期——日期不重要，判据绿了才算完。
