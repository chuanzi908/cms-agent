## 二、4 项验收用例（全部通过）

### 验收1：草稿直接审核 → 40901
```
POST /api/article/5/passAudit   （文章5为草稿 status=0）
→ {"code":40901,"message":"仅待审核状态可通过审核"}
```
草稿必须先提交审核，禁止越级审核通过。✅

### 验收2：乐观锁并发冲突 → 40900
```
POST /api/article/4            （新建文章4，version=1）
PUT  /api/article              {id:4, version:1}  → code=0，version=2   （先到先得）
PUT  /api/article              {id:4, version:1}  → {"code":40900,"message":"数据已被他人修改，请刷新后重试"}
```
并发编辑同一版本时后到者被拒绝，避免覆盖丢失。✅

### 验收3：删除有稿件账号 → 40903（跨模块守卫）
```
POST /api/article  (zhangsan token=2)  → 新建文章6，authorId=2
DELETE /api/users/2  (admin token=1)
→ {"code":40903,"message":"该账号下存在稿件，无法删除"}
```
M1 删除账号时通过公共层接口 ArticleAuthorCounter 回调 M2 计数，>0 拒绝删除。✅

### 验收4：分页仅 2 条 SQL，无 N+1
应用日志（mybatis-plus SQL 输出）：
```
==> Preparing: SELECT COUNT(*) AS total FROM cms_article a WHERE a.deleted = 0
==> Preparing: SELECT a.id, a.title, ..., u.nickname AS authorName, c.name AS categoryName
    FROM cms_article a LEFT JOIN sys_user u ... LEFT JOIN cms_category c ... ORDER BY a.create_time DESC LIMIT ?
```
分页统计 1 条 + 数据查询 1 条（一次 LEFT JOIN 带出作者昵称、分类名），全程无逐行二次查询。✅

## 五、如何复现

1. 初始化数据库：执行 `sql\schema.sql`（建库 cms 并导入种子数据）。
2. 构建：`mvn -B -pl startup -am package -DskipTests`。
3. 启动：`java -jar startup\target\cms-startup-1.0.0.jar`。
4. 验收脚本：`docs\cms-m2-test.http`（IDEA HTTP Client 直接运行），
   或按上文请求顺序用 Postman/Apifox 调用。
